# WTWR

This 'What To Wear' web app is used to display articles of clothes for the user to choose from based on the current weather conditions for their location. The user can also click on a clothing item card and display a larger view along with the temperature range the item would be suitable for.

WTWR connects to the OpenWeather API to retrieve the temperature and then display clothes based on that temperature. This was created based on this [figma design](https://www.figma.com/design/F03bTb81Pw8IDPj5Y9rc5i/Sprint-10-Project--WTWR?node-id=311-433&p=f&t=Ta4hmMOvTDbrqyBb-0).

## Project features

- Semantic HTML5
- Flexbox
- CSS
- JavaScript
- React
- And a flat BEM file structure
